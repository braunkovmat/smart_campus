# Домашние работы ПК №19–№24 (вариант 3)

Проекты на C# (.NET 8). Пакеты (Serilog, BCrypt.Net-Next, EF Core, Polly) подтягиваются из NuGet при сборке в Visual Studio.

- PK19_NuGetCheck – аудит версий NuGet-пакетов
- PK20_ArmMonitor – мониторинг и лог Serilog
- PK21_SmokeTests – дымовые тесты, протокол protocol.md (запуск с --tamper даёт сценарий ошибки)
- PK22_SmartCampusSystem – CampusClient + UpdaterHelper
- PK23_CampusOfflineTerminal – EF Core SQLite + Polly
- PK24_CampusSecurityTerminal – BCrypt, X.509, Serilog
